# 게임 난이도 정리 (전역 난이도 도입 준비용)

> 목적: 게임마다 제각각인 난이도 UI를 정리하고, 나중에 **전역 "쉽게 / 보통 / 어렵게"** 하나로
> 모든 게임을 조절하기 위한 매핑 기준을 만든다.

## 1. 라벨 표준화 (완료)

| 이전 | 표준 |
|---|---|
| `하 / 중 / 상` | `쉬움 / 보통 / 어려움` |
| `작은 미로 / 보통 미로 / 큰 미로` | `쉬움 / 보통 / 어려움` |
| `랜덤` | `무작위` |
| 구역 제목 `제한시간`, `시간 제한` | `제한 시간` |

`무작위`(v='random')와 `무제한`(시간 0)은 그대로 둔다.

## 2. 게임별 난이도 축 (현황)

각 게임의 **주 난이도 축**(전역 난이도가 조절할 대상)을 굵게 표시. 나머지는 부가 옵션.

## 3. 발견한 문제

1. **기본값이 최하인 게임이 많음** — 피아노·접힌 종이·전개도·블록코딩·스도쿠·반복청소·순간포착·진실거짓·규칙벗어난 등이 "쉬움"으로 시작해 절대 안 올라감. → 전역 난이도가 "보통"으로 시작하면 자동 해결.
2. **난이도 축이 여러 개로 흩어진 게임** — 위에서 본 모양(층/가로/세로), 세계퀴즈(모드/대륙), 명령 미리보기(맵/명령수). → 게임마다 **하나의 대표 난이도 함수**로 묶어야 전역 조절이 가능.
3. **난이도 개념이 아예 없는 게임 ~15개** — 사이먼·지도·좌표·톱니·거울대칭·시계·확률·숫자규칙·무게저울·햄버거·조건로봇·AND/OR·변수·함수 등. 대부분 조절 여지는 있음(자동 생성 파라미터).
4. **한자 급수 필터 없음** — 8급~6급이 섞여 나옴. 급수 선택 = 진짜 난이도.
5. **"무작위" 옵션이 일부에만 있음** — 있는 게임(3D블록, 스도쿠 등)과 없는 게임(미로, 피아노)이 갈림.
6. **제한 시간을 난이도로 쓰는 게임** vs **별도 축으로 두는 게임**이 섞임. 전역 난이도가 시간도 같이 조일지 결정 필요.

## 4. 제안하는 전역 구조

```js
// main.js
var GAME_DIFFICULTY = 'normal';   // 'easy' | 'normal' | 'hard'  (localStorage)
function setGameDifficulty(v) { ... }

// 각 게임은 (선택적으로) 자기 난이도 프리셋을 선언
GAME_DIFFICULTY_PRESETS.mazeGame = {
    easy:   { size: 6,  timeLimit: 0 },
    normal: { size: 8,  timeLimit: 0 },
    hard:   { size: 10, timeLimit: 20 }
};
// generateX 안에서:  var d = getDifficultyPreset('mazeGame') || mazeSettings;
```

- 홈에 전역 토글 하나 (`🙂 쉽게 / 🎯 보통 / 🔥 어렵게`).
- 게임별 setup 화면은 유지하되, 전역값을 **기본 선택**으로 반영("보통"이면 setup 열었을 때 보통이 눌려 있음).
- 난이도 없는 게임은 프리셋 미선언 → 전역값 무시(그대로).
- 이후 `getDifficultyPreset` 을 자동 조절(최근 정답률 기반)으로 바꾸면 적응형 난이도로 확장.

이 순서로 하면: **(1) 라벨 통일(완료) → (2) 게임별 대표 난이도 함수 정리 → (3) 프리셋 선언 + 전역 토글 → (4) 적응형**.
